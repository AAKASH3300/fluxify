# Changelog

All notable changes to Fluxify will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-28

### Added
- 🌊 Rebranded as Fluxify - "Transform anything into anything"
- Beautiful webview panel with cyberpunk-inspired design
- 25+ file format support (images, documents, data)
- Context menu integration for quick conversions
- Batch conversion support for multiple files
- Real-time progress tracking
- Configurable quality settings
- Success/error notifications
- Smart format detection
- 100+ conversion paths

### Supported Formats
- **Images**: PNG, JPG, JPEG, WebP, GIF, BMP, TIFF
- **Documents**: PDF, DOCX, DOC, HTML, Markdown, TXT
- **Data**: JSON, CSV, XML, YAML, YML

### Technical
- Built with TypeScript
- Powered by Sharp, pdf-lib, mammoth, docx, marked, and more
- Optimized for performance
- Memory-efficient processing
